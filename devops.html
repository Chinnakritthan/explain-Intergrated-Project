The Gate — ด่านตรวจก่อนให้คะแนนทุก PBI

ถ้า Gate ไม่ผ่าน “nothing new is Done”:
• TC-TR-1: เรียกเฉพาะ API ตัวเอง (ยกเว้น Keycloak)
• TC-TR-2: ห้ามใช้ JS Framework
• VM Check: int504check รัน docker (ต้องเป็น Docker Engine ไม่ใช่ Podman) ตรวจ 4 containers, UTF-8 และ package.json ของ backend ว่ามี express + @prisma/client

1️⃣ Sprint 1 — วางโครง 4 Containers & ผ่าน Gate แรก

เป้าหมาย: Deploy ขึ้น VM ที่ /intproj26/ip26-zap/ แยก 4 containers ให้คุยกันได้ และ import DB ด้วย UTF-8

  • Container 1 (proxy): Nginx รับ HTTPS 443 แยกเส้นทางไฟล์ static ไป frontend และ /api/v1/* ไป backend
  • Container 2 (frontend): เสิร์ฟไฟล์ HTML/CSS/JS ล้วน ภายใต้ path ของทีม
  • Container 3 (backend): รัน Node.js Express + Prisma (อ่าน DATABASE_URL ชี้ไป hostname ของ database container)
  • Container 4 (database): MySQL 8.4 รัน database/init.sql พร้อม utf8mb4
  • บทเรียนสำคัญจาก Sprint 1: หลายทีมตก Gate เพราะ package.json ของ backend ขาด @prisma/client หรือรัน Podman แทน Docker Engine

2️⃣ Sprint 2 — ย้ายสู่ Secret Path, Keycloak Redirect & Test Runner

เป้าหมาย: ย้ายระบบไป path ลับ (TR-01), ตั้งค่า Keycloak redirect และใช้ระบบ Run Now / Trial / Snapshot บน Sprint Portal

🔒 Secret Team Path

ย้ายจาก /intproj26/ip26-zap/ ไป /intproj26/<TEAM-PATH>/ (ชื่อทีม + สุ่ม 24 ตัว) ป้องกันการลอกงาน โดย /health ยังตอบ "team": "ip26-zap"

🔐 serve.json & Keycloak

เพิ่ม frontend/serve.json ("cleanUrls": false) เพื่อไม่ให้ npx serve ลบ .html ออกจาก URL จน redirect URI ของ Keycloak พังตอนรันเทสบน localhost:5173

⏱️ 3 รอบทดสอบของ Portal

Run Now (ทุก 15 นาที) · Trial (จันทร์ 18:00 ซ้อมใหญ่) · Snapshot (จันทร์ 23:59 คิดคะแนนจริง)

3️⃣ Sprint 3 — GitHub Actions CI Quality Gate 808 บรรทัด (ci.yml)

เป้าหมาย: สร้างระบบทดสอบอัตโนมัติครบทั้ง DB 11 ตาราง, Prisma, Auth ด้วย Mock JWKS Server และทดสอบ API ครบ PBI 1–12 ทุกครั้งที่ push

STEP 1–2Checkout & Setup Node.js 22

STEP 3Syntax, Merge Conflict & TR-05 Compliance

รัน node --check ตรวจ syntax ของไฟล์ .js ทุกไฟล์, เช็ค merge conflict markers และตรวจว่าไม่มี JS framework ต้องห้ามใน frontend

STEP 4Import database/init.sql & Verify All 11 Tables

รัน mysql --default-character-set=utf8mb4 < database/init.sql แล้ว query ตรวจจำนวนแถวเป๊ะทุกตาราง (51 courses, 97 schedules, 26 lecturers, 1,181 sessions) และตรวจภาษาไทย/en-dash ว่า UTF-8 ไม่เพี้ยน

STEP 5Prisma Validate & Verify All 11 Models

รัน npm ci, npx prisma validate, npx prisma generate และทดสอบ query จริงผ่าน Prisma Client ครบทั้ง 11 model

STEP 6Mock JWKS Server & Test PBI 1–10 (Required)

เทคนิคขั้นโปร! CI ใช้ jose สร้างคู่กุญแจ RSA ชั่วคราว + เปิด HTTP server จำลอง endpoint /certs (JWKS) แล้วส่ง KEYCLOAK_JWKS_URI ให้ Backend — ทำให้ทดสอบ PBI10 ได้ทุกเคส (token หมดอายุ, azp ผิดทีม, role ผิด, ข้าม studentId 403) แบบ Offline 100% โดยไม่พึ่ง Keycloak จริง!

ยิงทดสอบเคส clash (แถว 93–97, acceptClash: true) และเคส weekly sessions (วันหยุด, สัปดาห์สอบ, นอกเทอม)
